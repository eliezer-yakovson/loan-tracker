# לוח הלוואות חודשי

אפליקציית ווב מקומית לניהול ומעקב אחרי הלוואות חודשיות לפי בנקים או קטגוריות מותאמות אישית.

## יכולות מרכזיות

- יצירת עמודות דינמיות לכל בנק או קטגוריה.
- הוספת הלוואות עם שם הלוואה, שם מלווה, סכום מקורי, סכום חודשי, מספר תשלומים, תאריך לקיחה ויום חיוב חודשי.
- מעקב חודשי עם מעבר בין חודשים ושמירת היסטוריה מלאה בדפדפן.
- שכפול אוטומטי של נתוני החודש הקודם לחודש החדש במצב ממתין לאישור.
- מעבר מאדום לירוק באמצעות אישור או עריכה ידנית.
- סיכומים ברורים לפי בנק, לכלל ההלוואות, ולפי ימי חיוב בתוך החודש.
- כפתור העתקה לטבלה שאפשר להדביק ישירות באקסל.

## הפעלה

```bash
npm install
npm run dev
```

## בנייה

```bash
npm run build
```

## שמירת מידע

כל הנתונים נשמרים ב-localStorage של הדפדפן. אם תרצה בהמשך סנכרון בין מחשבים או גיבוי בענן, יהיה צורך להוסיף שרת או בסיס נתונים חיצוני.
